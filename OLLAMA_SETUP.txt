НАСТРОЙКА AKIRA + OLLAMA (Windows)

1) Установи/обнови Ollama и скачай модель:
   ollama pull qwen3.5:4b

2) Проверь, что Ollama отвечает:
   ollama ps
   Открой http://localhost:11434 — должно появиться "Ollama is running".

3) В папке проекта создай файл .env (если его ещё нет) и добавь:
   AI_PROVIDERS=ollama
   OLLAMA_MODELS=qwen3.5:4b
   OLLAMA_BASE_URL=http://localhost:11434/v1

   Если в .env уже есть другие настройки, не удаляй их без необходимости.
   Для выбора только Ollama поставь AI_PROVIDERS=ollama.
   Если хочешь резервного облачного провайдера, укажи его после ollama,
   например AI_PROVIDERS=ollama,gemini — но только если Gemini настроен.

4) Установи зависимости проекта:
   pip install -r requirements.txt

5) Полностью перезапусти Akira. Провайдеры считываются при запуске программы.

6) Напиши боту обычное сообщение. Для владельца инструменты доступны согласно
   правам проекта; гостям Telegram доступ к управлению компьютером закрыт.

Что исправлено в этой версии:
- Если Ollama-модель возвращает вызов зарегистрированного инструмента текстом
  вида {"name":"...","parameters":{...}}, Akira распознаёт его как действие,
  выполняет штатную функцию и просит модель сформулировать нормальный ответ.
- Такой технический JSON больше не отправляется как обычное сообщение, если
  он является вызовом реально зарегистрированного инструмента.
- В системный промпт добавлено указание не раскрывать внутренние tool payload.

Важно:
- Не отправляй никому свой .env: там могут быть Telegram-токен и другие секреты.
- Не включай токен бота в исходники и не публикуй его в GitHub.
- RTX 4060 8 GB: qwen3.5:4b — стартовый вариант. Большие модели могут частично
  выгружаться в RAM и отвечать медленнее.
