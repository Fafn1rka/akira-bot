## 1. 🤖 Бесплатная модель ИИ (Google Gemini)

Теперь Акира умеет работать через **Google Gemini** напрямую (быстро, умно и 100% бесплатно)!

### Как получить ключ за 1 минуту:
1. Зайди на [Google AI Studio](https://aistudio.google.com/)
2. Нажми **"Get API key"** -> **"Create API key"**
3. Скопируй ключ (он выглядит как `AIzaSy...`)
4. Добавь его в свой `.env` файл или переменные окружения:
   ```env
   GEMINI_API_KEY=твой_ключ_здесь
   ```
5. В `config.toml` можно настроить модель:
   ```toml
   [cloud]
   enabled = true
   provider = "gemini"
   model = "gemini-2.0-flash"   # или gemini-1.5-flash
   ```

> [!TIP]
> Gemini 2.0 Flash отвечает мгновенно, отлично понимает русский язык, пишет код и поддерживает вызов инструментов Акиры.

## 2. 🎮 3D Аватар (VRM модель)

В веб-интерфейсе Акиры уже работает полноценный 3D-движок на Three.js с поддержкой эмоций, моргания и движения губ!

### Как поставить свою 3D-модельку (девушку/аниме/персонажа):
1. Зайди на [VRoid Hub](https://hub.vroid.com/) или [Booth.pm](https://booth.pm/en/items?tags%5B%5D=VRM)
2. Найди любую понравившуюся модель с пометкой **VRM** и бесплатной загрузкой
3. Скачай файл (он будет иметь расширение `.vrm`)
4. Переименуй его в:
   ```
   assets/avatar.vrm
   ```
5. Запусти Акиру и открой в браузере: `http://localhost:8765`
6. Твоя моделька оживёт: будет смотреть за мышью, реагировать на диалог и говорить с тобой! Прямо внизу окна есть строка чата для отправки сообщений.

## 3. ☁️ Как запустить Акиру на сервере 24/7 (Бесплатно)

### Вариант 1: Oracle Cloud Always Free (Самый мощный, навсегда бесплатно)
Oracle Cloud предоставляет бесплатный сервер навсегда:
- **4 ядра ARM (Ampere)**
- **24 ГБ оперативной памяти**
- **200 ГБ диска**

#### Шаги:
1. Зарегистрируйся на [Oracle Cloud Free Tier](https://www.oracle.com/cloud/free/)
2. Создай инстанс: **Ubuntu 22.04 / 24.04** на архитектуре **VM.Standard.A1.Flex** (4 OCPU, 24 GB RAM)
3. Подключись по SSH:
   ```bash
   ssh ubuntu@ip_твоего_сервера
   ```
4. Установи Docker и Git:
   ```bash
   sudo apt update && sudo apt install -y git docker.io docker-compose
   sudo usermod -aG docker $USER
   ```
5. Клонируй свой репозиторий:
   ```bash
   git clone https://github.com/Fafn1rka/akira-bot.git
   cd akira-bot
   ```
6. Создай файл `.env` со своим ключом:
   ```bash
   echo "GEMINI_API_KEY=твой_ключ" > .env
   ```
7. Запусти контейнер 24/7:
   ```bash
   docker-compose up -d --build
   ```
8. Готово! Акира работает круглосуточно.

---

### Вариант 2: Запуск в фоне на своём ПК (Автозапуск с Windows)
Если не хочется настраивать удаленный сервер, можно запускать Акиру автоматически при старте твоего компьютера:
```bash
python manage.py autostart on
```
Акира будет стартовать вместе с Windows в свернутом виде и слушать команды.

## 4. 📱 Доступ с телефона
Акира умеет работать удалённо через веб-панель:
```bash
python manage.py phone
```
Команда покажет ссылку и QR-код. Отсканируй телефоном в той же Wi-Fi сети — и сможешь отдавать команды, писать в чат и слушать ответы.
