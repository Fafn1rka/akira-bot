# Навыки Акиры

Навык - папка `skills/<имя>/skill.py` с функцией `register(api)`.

    def register(api):
        api.keywords("слово-триггер")            # когда включать режим действий

        @api.tool("hello", "Say hello", {"name": {"type": "string", "description": "Who"}},
                  required=["name"], risk="safe", describe=lambda a: f"Поздороваться с {a['name']}")
        def hello(name):
            return f"Привет, {name}!"

- `risk="confirm"` (по умолчанию): перед выполнением Акира спросит пользователя. Всё, что меняет файлы,
  отправляет данные наружу или тратит деньги, должно быть `confirm`.
- `api.notify(text)` - Акира скажет/покажет уведомление (голос, аватар, телефон).
- `api.workspace` - папка Акиры; `api.settings` - ваши настройки из config.toml: `[skills.config.<имя>]`.

## Безопасность
Навык - это обычный Python-код с полными правами вашего пользователя. Устанавливайте только то,
что прочитали или написали сами.
- Навык НЕ работает, пока вы не включили его: `python manage.py skills enable <имя>` (показывает файлы).
- При включении запоминается SHA-256 кода. Если файл изменить позже - навык не загрузится,
  пока вы не проверите и не включите его заново.
