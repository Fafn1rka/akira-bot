# Акира

Голосовой ИИ-компаньон с живым персонажем на экране. Разговаривает на любые
темы, помнит тебя между перезапусками, может открывать программы и следить
за системой, отвечает в Telegram (в том числе видео-«кружком» с анимацией),
может писать первой, если долго тихо.

Работает одинаково на **Windows** и **Linux**.

## Установка

**Windows:** дважды кликни `install.bat`.
**Linux / macOS:** в терминале — `./install.sh`.

Скрипт создаст виртуальное окружение, поставит зависимости и скопирует
`.env.example` в `.env`. Дальше открой `.env` и впиши как минимум:

```
GEMINI_API_KEY=твой_ключ
```

Ключ бесплатный, получить тут: https://aistudio.google.com/apikey

Запуск:
- **Windows:** `run.bat`
- **Linux/macOS:** `./run.sh`

Можно просто печатать в открывшейся консоли — Акира ответит текстом. Если
доступны микрофон и колонки — она ещё и заговорит вслух и появится персонаж
поверх рабочего стола.

## Голос (микрофон)

Скажи «**Акира**» и после — свою фразу (или просто «Акира» — она откликнется
и подождёт продолжения). На Linux для микрофона иногда нужно доставить
системный пакет:

```
sudo apt-get install portaudio19-dev   # Debian/Ubuntu
sudo dnf install portaudio-devel       # Fedora
sudo pacman -S portaudio               # Arch
```

Если микрофона нет или пакеты не встали — ничего страшного, просто печатай
в консоли, остальное работает как обычно.

## Персонаж на экране

Прозрачное окошко без рамки поверх всех окон. Перетаскивается мышью (позиция
запоминается), двойной клик — свернуть/развернуть. Если не нужно —
`ENABLE_AVATAR=false` в `.env`. Если не установлен PySide6 — просто не
появится, бот от этого не пострадает.

## Telegram

1. Напиши **@BotFather** в Telegram → `/newbot` → получишь токен.
2. Впиши его в `.env` как `TELEGRAM_BOT_TOKEN`.
3. Запусти Акиру, напиши своему боту `/id` — он покажет твой числовой ID.
4. Впиши этот ID в `.env` как `TELEGRAM_OWNER_ID` (это даёт полный доступ,
   включая управление компьютером — храни токен и это значение в секрете).
5. Перезапусти Акиру.

По умолчанию бот отвечает **видео-кружком** с говорящим персонажем
(`TELEGRAM_REPLY_MODE=video`). Можно переключить на голосовые (`voice`) или
только текст (`text`) — в `.env` или прямо в чате командой `/mode voice`.

Друзьям можно разрешить просто поболтать (без доступа к твоему ПК) — впиши
их ID через запятую в `TELEGRAM_ALLOWED_IDS`, или включи `TELEGRAM_PUBLIC=true`,
чтобы отвечать вообще всем в личке.

## Twitch (необязательно)

Впиши `TWITCH_CHANNEL` в `.env` — Акира будет читать чат стрима. Чтобы она
могла ещё и писать в ответ, добавь `TWITCH_OAUTH_TOKEN` (получить:
https://twitchapps.com/tmi/) и `TWITCH_BOT_NICK`.

## Управление компьютером

Акира умеет открывать программы/сайты, крутить громкость, проверять
загрузку системы — работает и на Windows, и на Linux. Выключить:
`ENABLE_SYSTEM_COMMANDS=false`.

Выполнение консольных команд по умолчанию **выключено**
(`ENABLE_TERMINAL_COMMANDS=false`) — это единственная по-настоящему опасная
возможность. Если включишь, Акира всё равно не выполнит команду сама: она
только предложит её и попросит тебя написать «подтверждаю».

## Публикация на GitHub

```
python tools/push_to_github.py https://github.com/ТВОЙ_ЛОГИН/РЕПОЗИТОРИЙ.git
```

Файл `.env` в репозиторий не попадёт (см. `.gitignore`) — скрипт это
дополнительно проверяет перед отправкой. На другом компьютере: склонируй
репозиторий, запусти `install.sh`/`install.bat`, впиши свои ключи в новый
`.env` — и всё точно так же заработает.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | точка входа, всё запускает и связывает |
| `config.py` | настройки из `.env` |
| `persona.py` | характер Акиры, системные промпты |
| `brain.py` | Gemini + инструменты + память |
| `memory.py` | память на диске (`data/`) |
| `voice.py` | синтез речи, воспроизведение |
| `voice_listener.py` | распознавание речи с микрофона |
| `system_control.py` | открыть приложение / громкость / статус системы |
| `character.py` | рисует персонажа (кадр как функция времени/состояния) |
| `media.py` | ffmpeg: аудио → видео-кружок для Telegram |
| `avatar.py` / `avatar_state.py` | окно персонажа на рабочем столе |
| `telegram_bot.py` | Telegram-бот |
| `twitch_bot.py` | чтение/ответы в чате Twitch |
| `tools/make_assets.py` | пересобрать картинки персонажа из карточки |
| `tools/push_to_github.py` | безопасная публикация на GitHub |

## Если что-то не работает

- **Нет звука/голоса** — проверь, что установлен `ffmpeg` (Windows: пакет
  `imageio-ffmpeg` из `requirements.txt` ставит его сам; Linux: обычно уже
  есть, иначе `sudo apt-get install ffmpeg`).
- **Не открывается окно персонажа** — `pip install PySide6`.
- **Ошибка Gemini** — проверь `GEMINI_API_KEY` и интернет.
- Логи лежат в `logs/akira.log`.
