# Акира

Голосовой ИИ-компаньон с живым персонажем на экране. Разговаривает на любые темы, помнит тебя между
перезапусками, открывает программы, следит за системой, ищет в интернете, ставит напоминания, понимает
файлы и картинки. Живёт в консоли, на голосе, в Telegram и в Discord — и везде это одна и та же Акира
с одной памятью.

Работает на **Windows** и **Linux**. Лучше всего — Python 3.11 или 3.12.

> Переезжаешь с Linux на Windows (или наоборот)? Пошаговая инструкция и скрипт для переноса ключей и памяти —
> в файле **WINDOWS_SETUP.md**.

## Быстрый старт (Windows)

1. Установи Python с https://python.org. На первом экране установщика поставь галочку
   **Add python.exe to PATH**.
2. Дважды кликни `install.bat` — он создаст окружение, поставит всё нужное и создаст файл `.env`.
3. Открой `.env` блокнотом и впиши ключ: `GEMINI_API_KEY=...`
   (бесплатно: https://aistudio.google.com/apikey).
4. Дважды кликни `run.bat`. Можно сразу печатать в консоли — Акира ответит.

## Linux

`./install.sh`, затем `./run.sh` (консоль) или `./run_gui.sh` (окно). Системные пакеты
(Debian / Ubuntu / Linux Mint):

```
sudo apt-get install -y libportaudio2 portaudio19-dev libopus0 ffmpeg libxcb-cursor0 playerctl
```

`libxcb-cursor0` нужна окну: без неё Qt пишет «Could not load the Qt platform plugin "xcb"».

**Значок в меню и на столе:** `./create_shortcut.sh` — один раз. После этого Акира открывается как
обычная программа, без терминала; если значок на рабочем столе не запускается — ПКМ по нему →
«Разрешить запуск». Если окно не открывается, смотри `logs/gui.out`.

Скрипты для Linux: `check.sh` (диагностика), `test_mic.sh` (микрофон), `spotify_login.sh` (вход в Spotify).

Что на Linux работает иначе, чем на Windows:
- **«Посмотри на экран»** — только в сессии **X11** (в Linux Mint Cinnamon она по умолчанию), в Wayland нельзя.
- **Пауза / следующий трек** — через `playerctl` (пакет выше) и запущенный плеер.
- **Значок в трее** — в Cinnamon и KDE есть; в чистом GNOME по умолчанию нет (нужно расширение AppIndicator).
- **`.exe` и установщик** (`build_exe.bat`, `installer.iss`) — только для Windows.
- Остальное (голос, Telegram, Discord, сценарии, брифинг, музыка, Spotify) — то же самое, что в остальном README
  (вместо `.venv\Scripts\pip` пиши `.venv/bin/pip`).

## Голос (Windows и Linux)

Скажи «**Акира**, открой ютуб». Только «Акира» — она откликнется и будет ждать команду.
После ответа ~25 секунд можно говорить **без имени** — как в обычном разговоре.

**Что нужно:** микрофон, колонки или наушники, интернет (для голоса Акиры и, по умолчанию, для
распознавания). Больше ничего ставить не надо — `install.bat` уже всё поставил.

**Проверка микрофона** — дважды кликни `test_mic.bat`: он покажет список микрофонов и в реальном времени
напишет, что Акира от тебя слышит. Если тут работает — заработает и в самой Акире.

**Если она тебя не слышит:**
- Windows → Параметры → Конфиденциальность → Микрофон → включи доступ, в том числе
  «Разрешить классическим приложениям».
- Микрофонов несколько, и выбрался не тот — запусти `test_mic.bat`, найди свой номер в списке и впиши
  в `.env`: `VOICE_MIC_DEVICE=3` (или часть названия: `VOICE_MIC_DEVICE=Realtek`).
- Тихо или шумно — порог громкости подбирается сама. Если не помогло, задай вручную:
  `VOICE_ENERGY_THRESHOLD=400` (чем меньше число, тем чувствительнее).
- Имя распознаётся плохо — скажи чётче или добавь свои варианты: `WAKE_WORDS=акира,акиру,akira`.

**Она слышит саму себя?** Нет: пока Акира говорит, микрофон автоматически отключается (и ещё на
доли секунды после). Наушники не обязательны.

**Точнее и без интернета — локальное распознавание (Whisper):**
```
.venv\Scripts\pip install -r requirements-whisper.txt
```
В `.env` можно оставить `STT_ENGINE=auto` — включится само. Первый запуск скачает модель (около 500 МБ)
и займёт пару минут. Слабый компьютер — `WHISPER_MODEL=base`, хорошая видеокарта NVIDIA —
`WHISPER_DEVICE=cuda` и `WHISPER_COMPUTE=float16`.
Без Whisper используется Google-распознавание: оно бесплатное и без ключа, но нужен интернет.

**Голос Акиры** — Microsoft edge-tts (женские голоса). Если интернета нет, она говорит встроенным
голосом Windows (`VOICE_OFFLINE_FALLBACK=true`).

## AI: несколько ключей, запасные модели, другие нейросети

Один ключ Gemini — уже достаточно. Чтобы Акира никогда не «замолкала» из-за лимитов, добавь запасных
в `.env` (примеры — в `.env.example`):

```
GEMINI_API_KEYS=ключ1,ключ2,ключ3
GEMINI_MODELS=gemini-3.6-flash,gemini-2.5-flash
AI_PROVIDERS=gemini,groq,ollama
GROQ_API_KEYS=...
GROQ_MODELS=llama-3.3-70b-versatile
OLLAMA_MODELS=llama3.1
```

Если лимит кончился, ключ не подошёл или сервис перегружен — Акира сама и незаметно переходит на
следующий вариант, а через какое-то время возвращается к лучшему. Разговор не теряется.
Поддерживаются: **Gemini, OpenAI, Claude (Anthropic), Groq, OpenRouter, DeepSeek, Mistral**,
локальные **Ollama** и **LM Studio** (бесплатно, без ключа и интернета) и любой OpenAI-совместимый сервис
(`CUSTOM_BASE_URL`). Названия моделей у провайдеров меняются — сверяй их с документацией.

## Файлы и картинки

Акира понимает несколько файлов сразу: картинки, PDF, аудио/видео (что поддерживает выбранный AI) и
любые текстовые файлы (`.txt`, `.py`, `.json`, `.csv` и т.д.).

- **Консоль:** `/файл путь1 путь2 ... вопрос`, например `/файл C:\скрин1.png C:\скрин2.png что не так?`
  Файлы можно перетащить мышью прямо в окно консоли; пути с пробелами берутся в кавычки.
- **Telegram:** присылай фото, документы, аудио — хоть целым альбомом. Подпись = вопрос.
- **Discord:** прикрепляй файлы к сообщению.

Файлы относятся к текущему сообщению: в памяти остаётся ответ Акиры, а не сам файл.
Лимиты: до 10 файлов, до 8 МБ каждый.

## Своя программа с окном (не консоль)

По умолчанию Акира работает в чёрном окне консоли. Есть и настоящее окно — со вкладками «Чат»,
«Статус», «Сценарии», «Настройки» и «Журнал» — и его можно превратить в отдельную программу
с иконкой на рабочем столе, как игру или Excel.

### Быстрый способ — окно + ярлык

1. `install.bat` (если ещё не запускал) — он же ставит пакет для окна.
2. **`create_shortcut.bat`** — один раз. Появится ярлык «Акира» на рабочем столе и в меню Пуск.
3. Открывай Акиру этим ярлыком. Окно открывается без чёрной консоли, голос/Telegram/Discord
   работают как обычно — просто вместо печати в чёрном окне теперь настоящее окно:
   - **Чат** — написать Акире текстом и увидеть ответ;
   - **Статус** — подключён ли AI, слушает ли микрофон, отвечают ли Telegram и Discord;
   - **Сценарии** — посмотреть, изменить и сразу же включить сценарий («рабочий режим» и т.п.);
   - **Настройки** — то же самое, что раньше правилось в `.env` блокнотом, но полями и галочками;
     после сохранения окно само не перезапускается — закрой Акиру и открой заново;
   - **Журнал** — то же самое, что `logs\akira.log`, но прямо в окне.
   - Крестик у окна сворачивает Акиру в трей (в правом нижнем углу экрана) — она продолжает
     работать. Чтобы выйти совсем: правой кнопкой по значку в трее -> «Выход».
4. Если что-то не открылось — `run_gui.bat` покажет текст ошибки в консоли (в отличие от ярлыка).

### Полноценный `.exe` (без Python на виду)

`build_exe.bat` собирает Акиру в один файл `dist\AkiraGUI.exe` — его можно скопировать,
закрепить на панель задач, запускать без установленного отдельно Python. Собирать нужно на своём
компьютере (несколько минут, один раз нужен интернет); `.env` и папка `data` при этом остаются
рядом с `.exe` отдельными файлами — сам `.exe` их не содержит.

### Настоящий установщик (как у игр — с иконками и удалением из «Параметров»)

1. Сначала `build_exe.bat`.
2. Поставь бесплатный **Inno Setup Compiler**: jrsoftware.org/isinfo.php (один раз).
3. Открой `installer.iss` через Inno Setup Compiler → Build → Compile.
4. Получится `Output\AkiraSetup.exe` — обычный установщик: мастер установки, ярлыки, а удаление
   потом — через «Параметры Windows -> Приложения», как у любой другой программы.

Этот шаг я не мог проверить на настоящем Windows — если что-то в сборке пойдёт не так, пришли
текст ошибки.

## Музыка: выбирай и переключай сама

«Акира, включи Believer» или «поставь что-нибудь от Imagine Dragons» — она поищет в твоей папке
с музыкой и включит нужный трек. Если такой песни у тебя нет — поищет и откроет на YouTube.

- **Где искать:** по умолчанию — папка «Музыка» твоего профиля. Своя папка — `MUSIC_DIR=D:\Музыка`
  в `.env` (или в окне: вкладка «Настройки» → «Музыка»).
- **Точнее находит,** если установлен пакет `mutagen` (он читает теги файла — исполнитель, название),
  без него ищет по именам файлов. Уже есть в `requirements.txt`, ставится вместе с install.bat.
- **YouTube-поиск** — через пакет `yt-dlp`, тоже уже в `requirements.txt`, ключ или аккаунт не нужны.
  Отключить: `MUSIC_YOUTUBE_FALLBACK=false` — тогда, если своей музыки нет, она так и скажет.
- **Пауза, следующий, предыдущий трек** — команды те же, что раньше («пауза», «дальше»): они управляют
  тем, что уже играет, через `media_control`, какой бы плеер ни открылся.
- **«Покажи, что у меня есть»** — спроси «что у меня есть из рока» или просто «какая у меня есть музыка».
- Локальный файл открывается тем плеером, что назначен в Windows по умолчанию для музыки.

### Spotify

Хочешь искать не только по своим файлам, а по всему каталогу Spotify (и правда включать там трек) —
подключи Spotify. Нужен **Spotify Premium**: без него Spotify не разрешает запускать воспроизведение
через API (искать можно и на бесплатном, а вот включить — нет).

1. https://developer.spotify.com/dashboard → **Create app**.
2. В настройках приложения Redirect URI впиши **точно**: `http://127.0.0.1:8888/callback`
3. Client ID и Client Secret со страницы приложения → в `.env`:
   ```
   SPOTIFY_CLIENT_ID=...
   SPOTIFY_CLIENT_SECRET=...
   ```
   (или в окне → «Настройки» → «Музыка»)
4. Запусти **`spotify_login.bat`** — один раз. Откроется браузер: войди в Spotify и разреши доступ.
5. На устройстве, где должна играть музыка (телефон или компьютер), приложение Spotify должно быть
   **открыто** (хотя бы на паузе) — иначе Spotify не знает, куда включать трек.

После этого «Акира, включи ...» ищет по порядку: твои файлы → Spotify → YouTube. Авторизация проходит
только через `spotify_login.bat` в обычном окне консоли — сама Акира (в окне, фоне, Telegram) никогда
не пытается сама открыть браузер для входа, чтобы нигде не зависнуть в ожидании ответа.

## Что Акира умеет делать по просьбе

Говори (голосом, в Telegram, в Discord или пиши в консоли) как обычному человеку:

- «Открой ютуб», «сделай тише», «как там компьютер» — открыть программу или сайт, громкость, состояние системы.
- «Напомни через 20 минут выключить чайник» — скажет вслух и напишет в Telegram и Discord.
- «Найди в интернете, что нового про ...» — поиск и пересказ.
- «Пауза», «следующий трек» — управление плеером (Spotify, браузер, VLC...).
- **Сценарии, экран и утренний брифинг** — ниже.

Отключить: `ENABLE_EXTRA_TOOLS=false` (всё из этого списка), `ENABLE_SYSTEM_COMMANDS=false` (управление
компьютером). Консольные команды по умолчанию **выключены** (`ENABLE_TERMINAL_COMMANDS=false`); если
включишь, Акира всё равно ничего не выполнит сама — только предложит и дождётся «подтверждаю».

### Сценарии («включи рабочий режим»)

Одна фраза — несколько действий сразу. «Акира, включи рабочий режим» — откроется VS Code и GitHub, громкость
станет 25. Из коробки есть: **рабочий режим, игровой режим, отдых, тишина**.

Свои сценарии — в файле `data/scenes.json` (он создаётся сам при первом запуске; правь его обычным
текстовым редактором, перезапускать Акиру не нужно):

```json
{
  "учёба": {
    "aliases": ["учиться", "занятия"],
    "say": "Включаю режим учёбы.",
    "steps": [
      {"open": "vscode"},
      {"url": "https://www.youtube.com"},
      {"volume": 20},
      {"media": "pause"}
    ]
  }
}
```

Шаги: `open` (программа или сайт), `url` (ссылка http/https), `volume` (0–100), `media`
(`play_pause`, `pause`, `play`, `next`, `previous`), `wait` (пауза, до 5 секунд). Консольных команд в
сценариях нет намеренно: Акира выбирает только *название* сценария, а что он делает — решает твой файл.

### «Посмотри на экран»

Скажи: «Акира, посмотри на экран», «что у меня на экране?» или просто «помоги с этой ошибкой» —
она сделает снимок экрана и разберёт его. Работает только по твоей просьбе, ничего не снимается в фоне.

Что важно знать:
- Снимок уходит выбранному AI-провайдеру (Google, OpenAI...). Не проси смотреть на экран, когда там
  пароли или чужая переписка. Выключить совсем: `ENABLE_SCREEN_VISION=false`.
- Пока Акира рассматривает снимок, у неё **нет инструментов** — текст на экране (сайт, письмо) не
  сможет заставить её открыть что-то или выполнить команду.
- **Linux:** работает в сессии **X11** (в Linux Mint Cinnamon она по умолчанию). В Wayland система
  запрещает программам снимать экран — Акира так и скажет. Переключатель сессии — на экране входа.
- Несколько мониторов: `SCREEN_MONITOR=1` (основной), `2` (второй), `0` (все сразу).
- Это может делать только владелец.

### Утренний брифинг

В заданное время Акира сама здоровается: какой сегодня день, какая погода и что у тебя в напоминаниях
на сегодня. Говорит вслух за компьютером и пишет в Telegram и Discord.

```
MORNING_BRIEFING=true
BRIEFING_TIME=08:30
BRIEFING_CITY=Berlin
```

Без `BRIEFING_CITY` погоды не будет (город нужно указать самому). Погода — бесплатный сервис Open-Meteo,
ключ не нужен. Раз в день, повторно не здоровается. Включил компьютер позже назначенного времени —
поздоровается при запуске, но не позже чем через 4 часа. Проверить сразу: команда `/брифинг` в консоли,
или попроси «Акира, что у нас сегодня?». Напоминания хранятся только пока Акира запущена.

## Telegram

1. Напиши **@BotFather** → `/newbot` → получишь токен → впиши в `.env` как `TELEGRAM_BOT_TOKEN`.
2. Запусти Акиру и напиши своему боту `/id` — он покажет твой числовой ID.
3. Впиши его в `.env` как `TELEGRAM_OWNER_ID` (это полный доступ, включая управление ПК —
   храни токен и ID в секрете) и перезапусти Акиру.

Ответы: видео-«кружок» с говорящей Акирой (`TELEGRAM_REPLY_MODE=video`), голосовое (`voice`) или
текст (`text`) — можно переключить в чате командой `/mode voice`. Друзьям можно разрешить просто
поболтать (без доступа к ПК): их ID в `TELEGRAM_ALLOWED_IDS`, либо `TELEGRAM_PUBLIC=true` для всех.

## Discord

1. https://discord.com/developers/applications → **New Application** → вкладка **Bot** →
   **Reset Token** → впиши в `.env`: `DISCORD_BOT_TOKEN=...`
2. Там же, ниже, включи **MESSAGE CONTENT INTENT** — без него бот не видит текст сообщений.
3. **OAuth2 → URL Generator**: отметь `bot` и права «Send Messages» и «Read Message History»,
   открой полученную ссылку и добавь бота на свой сервер (или просто напиши ему в личку).
4. Свой ID: Discord → Настройки → Расширенные → Режим разработчика; ПКМ по своему имени →
   «Копировать ID». Впиши в `.env`: `DISCORD_OWNER_ID=...`
5. Перезапусти Акиру. Бот отвечает в личке, при упоминании `@Акира` и в каналах из
   `DISCORD_CHANNEL_IDS`. Ты — владелец (все инструменты), остальные — гости (только болтовня).
   Команда `!сброс` очищает память диалога.

### Голос в голосовом канале Discord

Акира умеет **говорить** в голосовом канале (слушать людей в канале она пока не умеет — пиши ей текстом).

1. Права бота при добавлении на сервер: к обычным добавь **Connect** и **Speak** (OAuth2 → URL Generator).
2. Зайди сам в голосовой канал и напиши в любом текстовом канале сервера: **`!зайди`** — она придёт к тебе.
3. Теперь её ответы на твои сообщения в чате сервера ещё и озвучиваются в канале. Остальным она отвечает
   только текстом (чтобы никто не заставлял её кричать в войсе); разрешить всем — `DISCORD_VOICE_ALL=true`.
4. **`!скажи всем привет`** — произнести именно эту фразу. **`!выйди`** — уйти. Если в канале не остаётся
   людей, она уходит сама через 30 секунд.

Команды `!зайди`, `!выйди`, `!скажи` работают только у владельца и без упоминания бота.
Для голоса нужны пакет PyNaCl (ставится вместе с `discord.py[voice]` из `requirements.txt`) и библиотека
Opus: **Linux — `sudo apt install libopus0`**, Windows и macOS — ничего ставить не нужно.


## Twitch (необязательно)

Впиши `TWITCH_CHANNEL` — Акира будет читать чат стрима. Чтобы она ещё и писала, добавь
`TWITCH_OAUTH_TOKEN` (https://twitchapps.com/tmi/) и `TWITCH_BOT_NICK`.

## Общая память

Голос, консоль, Telegram и Discord помнят тебя вместе (`SHARED_OWNER_MEMORY=true`). Факты о тебе,
которые раньше накопились отдельно в Telegram, при первом запуске переносятся в общую память.
Хочешь по-старому, у каждого канала своя память, — `SHARED_OWNER_MEMORY=false`.
Память лежит в `data/`. Внимание: `/reset` в Telegram очищает общую память.

## Что изменилось в этой версии

- Микрофон работает через `sounddevice`, **PyAudio больше не нужен** (его на Windows чаще всего
  и не удавалось поставить).
- Акира не слышит саму себя; есть выбор микрофона, авто-подбор порога и `test_mic.bat`.
- Распознавание: Google или локальный Whisper; тот же движок понимает голосовые из Telegram.
- Много ключей/моделей и разные нейросети с автоматическим переключением.
- Файлы и картинки (консоль, Telegram-альбомы, Discord), напоминания, поиск, управление плеером.
- Discord-бот с **голосом в голосовом канале**. Общая память владельца.
- **Сценарии** («рабочий режим»), **утренний брифинг**, **«посмотри на экран»**; управление плеером и на Linux (playerctl).
- Исправлено: программа закрывалась сама, если выключить `IDLE_CHAT_ENABLED` или не установить пакет
  Telegram; при выходе консоль могла «зависнуть», пока не нажмёшь Enter.

## Если что-то не работает

- **Логи** — `logs/akira.log`. При вопросах присылай последние строки (ключи в них скрыты).
- **Не слышит** — `test_mic.bat` и раздел «Голос на Windows» выше.
- **Нет голоса Акиры** — проверь интернет; `ffmpeg` ставится вместе с `imageio-ffmpeg`.
- **Ошибка AI / «ключ не подошёл»** — проверь ключ и интернет; при нескольких ключах Акира
  пишет в лог, какой отключила.
- **Не открывается окно персонажа** — `pip install PySide6`, либо `ENABLE_AVATAR=false`.
- **Ярлык/`.exe` не запускается** — сначала попробуй `run_gui.bat`: он покажет текст ошибки.
- **Discord молчит** — включён ли Message Content Intent, верный ли `DISCORD_OWNER_ID`.
- **`!зайди` не работает** — ты сам должен сидеть в голосовом канале; нужны права Connect/Speak, `libopus0`
  (Linux) и пакет PyNaCl; причина — в ответе Акиры и в `logs/akira.log`.
- **«Посмотри на экран» не работает на Linux** — включена сессия Wayland (нужна X11), либо не установлен `mss`.
- **Пауза/следующий трек молчит на Linux** — `sudo apt install playerctl`, и плеер должен быть запущен.
- **Брифинг не приходит** — проверь `MORNING_BRIEFING=true`, формат `BRIEFING_TIME=08:30`; смотри `logs/akira.log`.
